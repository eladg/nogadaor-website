# שאלון המיקוד: חיבור לגיליון גוגל (הוראות לנוגה)

כל מי שמסיים את השאלון נשמר כשורה בגיליון: מי עובד בעסק, הציונים, והתשובה לכל שאלה.
מי שמשאיר שם ומייל כדי לפתוח את התוצאה, הפרטים נכתבים באותה שורה (שם, מייל, טלפון, ואם אישר דיוור).
**לא צריך טופס של גוגל (Google Forms).** השאלון נשאר באתר כמו שהוא, והאתר כותב לגיליון מאחורי הקלעים.

## מה עושים (כ-10 דקות)

1. **פותחים גיליון חדש** ב-Google Sheets, בחשבון שלך. שם לדוגמה: "שאלון המיקוד – תשובות".
2. בתפריט: **תוספים ← Apps Script** (Extensions ← Apps Script). נפתחת לשונית עם עורך קוד.
3. **מוחקים** את מה שכתוב בעורך, ו**מדביקים** את כל התוכן של הקובץ `apps-script.gs` (באותה תיקייה).
4. **בוחרים סיסמה משותפת:** בשורה `const SECRET = 'להחליף-במחרוזת-ארוכה';` מחליפים את הטקסט שבין הגרשיים במחרוזת ארוכה באנגלית ומספרים, בלי רווחים (למשל 30 תווים). **לא שולחים אותה בצ'אט.**
5. שומרים (סמל הדיסקט או Ctrl+S).
6. **בדיקה:** למעלה בוחרים את הפונקציה `testWrite` ולוחצים **הפעלה** (Run). גוגל יבקש הרשאה: בוחרים את החשבון שלך, "Advanced" ← "Go to ... (unsafe)" ← "Allow". זה הקוד שלך בגיליון שלך, ולכן גוגל מזהיר. בגיליון אמורה להופיע לשונית "תשובות" עם שורת בדיקה. אפשר למחוק את השורה.
7. **פרסום הקוד:** למעלה מימין **Deploy ← New deployment**. בגלגל השיניים בוחרים **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
   - לוחצים Deploy, ומעתיקים את ה-**Web app URL** (נגמר ב-`/exec`).
8. **שולחים לאלעד** (לא בצ'אט כאן) את שני הדברים, כדי שיכניס אותם בהגדרות האתר ב-Netlify (Site configuration ← Environment variables):
   - `QUIZ_SHEET_URL` = כתובת ה-Web app
   - `QUIZ_SHEET_SECRET` = הסיסמה המשותפת מסעיף 4
   אחרי שהוא מכניס אותם, צריך לבנות את האתר מחדש (Deploy) כדי שזה ייכנס לתוקף.

## למה "Anyone"?
כדי שהאתר יוכל לכתוב לגיליון. בלי הסיסמה המשותפת, הקוד מסרב לכתוב, והכתובת והסיסמה שמורות רק בשרת של האתר, לא בדפדפן של המבקרים. הגיליון עצמו נשאר פרטי שלך.

## אם משנים את הקוד בעתיד
עורכים, שומרים, ואז **Deploy ← Manage deployments ← עריכה (עיפרון) ← Version: New version ← Deploy**. הכתובת נשארת אותה כתובת.

## מה יופיע בגיליון
תאריך · מזהה · סטטוס ("הושלם" / "השאיר פרטים") · מי עובד בעסק · ציון כללי · ציון לכל אחד מ-4 התחומים · עמודה לכל שאלה (התשובה שנבחרה) · שם · מייל · טלפון · מאשר דיוור · תאריך השארת פרטים.
כשמוסיפים או משנים שאלה באתר, נוספת לבד עמודה חדשה.

## סטטיסטיקות והשוואה
כשיצטברו שורות, Claude יבנה לשונית סטטיסטיקות (כמה מילאו, כמה השאירו פרטים, ממוצע לכל תחום, עצמאים מול עסקים עם עובדים), ובהמשך את ההשוואה לאחרים בתוצאה.

## לפני שמפרסמים באתר
מדיניות פרטיות ונוסח ההסכמה לדיוור, עם איש מקצוע. היום עמוד הפרטיות "בהכנה".
